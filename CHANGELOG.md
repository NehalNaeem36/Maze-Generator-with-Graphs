# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-01-XX

### Added
- Initial release
- Spanning tree maze generation using recursive DFS
- BFS pathfinding for shortest path calculation
- 90% preservation randomization system
- Path protection mechanism (shortest path never modified)
- ASCII visualization with path highlighting
- Maze validation system
- Configurable maze dimensions
- Start tile at (0,0), random end tile placement

### Features
- `tile` class for maze cell representation
- `TileList` doubly-linked list container
- `maze` class with full generation pipeline
- Guaranteed solvable mazes
- Bidirectional path management

### Documentation
- Comprehensive README with algorithm explanation
- Sample maze output
- Usage instructions
- Code structure overview
