# Contributing to Maze Generator with Graphs

Thank you for your interest in contributing! 🎉

## How to Contribute

1. **Fork the repository**
2. **Create a feature branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes**
   - Follow existing code style
   - Add comments for complex logic
   - Test your changes thoroughly
4. **Commit with clear messages**
   ```bash
   git commit -m "Add feature: description"
   ```
5. **Push to your fork**
   ```bash
   git push origin feature/your-feature-name
   ```
6. **Open a Pull Request**

## Code Style Guidelines

- Use camelCase for variables and functions
- Use PascalCase for classes
- Add comments for non-obvious logic
- Keep functions focused and modular
- Use meaningful variable names

## Ideas for Contributions

- [ ] Add more maze generation algorithms (Prim's, Kruskal's, Wilson's)
- [ ] Implement GUI visualization
- [ ] Add iterative tile initialization for larger mazes
- [ ] Create maze solver with animation
- [ ] Add difficulty levels
- [ ] Implement save/load maze functionality
- [ ] Add unit tests
- [ ] Optimize for very large mazes (>1000×1000)

## Reporting Bugs

Open an issue with:
- Description of the bug
- Steps to reproduce
- Expected vs actual behavior
- Your environment (OS, compiler version)

## Questions?

Feel free to open an issue for discussion!
